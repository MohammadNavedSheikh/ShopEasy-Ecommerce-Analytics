
# ShopEasy - E-Commerce Sales & Customer Analytics

## Project Overview
Analyzed e-commerce sales data using Python and Pandas.

## Key Metrics
- Total Sales: 52452209.31
- Total Profit: 8669667.21
- Unique Orders: 10000

## Analysis Performed
- Monthly Sales Trend
- Category-wise Sales and Profit
- Top 10 Products
- State-wise Sales
- Payment Mode Analysis
- Top 10 Customers
- Average Order Value
- Profit Margin
- Discount and Shipping Analysis
- Customer Segmentation

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Business Objective
Identify sales trends, profitable categories, valuable customers,
and opportunities for improving business performance.
